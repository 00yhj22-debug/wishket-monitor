============================================================
[2] 이 폴더 파일들을 그 Repo에 올리기
============================================================
A. 가장 쉬운 방법 - 웹 업로드:
   1. Repo 페이지에서 "uploading an existing file" 링크 클릭
      (또는 "Add file" > "Upload files")
   2. 이 폴더의 파일들을 드래그해서 업로드:
      - monitor.py
      - requirements.txt
      - seen.json
      - .gitignore
   3. 폴더(.github/workflows/check.yml)는 웹 업로드로는
      폴더 통째로 안 올라가므로 ↓ 처럼 따로:
   4. "Add file" > "Create new file" 클릭
   5. 파일명 칸에 정확히 입력:
      .github/workflows/check.yml
      (슬래시 / 를 입력하면 자동으로 폴더가 만들어짐)
   6. 메모장으로 check.yml 열어서 내용 복붙
   7. 페이지 맨 아래 "Commit new file"

   * .github 같은 점(.)으로 시작하는 파일은 윈도우 탐색기에
     숨겨질 수 있으니, 메모장에서 직접 복붙하는 게 안전합니다.

B. Git 명령줄에 익숙하면:
   git init
   git add .
   git commit -m "initial"
   git branch -M main
   git remote add origin https://github.com/<USER>/<REPO>.git
   git push -u origin main

============================================================
[4] Workflow 권한 확인
============================================================
1. Repo "Settings" > 왼쪽 "Actions" > "General"
2. 맨 아래 "Workflow permissions" 섹션
3. "Read and write permissions" 선택 ★
   (seen.json 자동 커밋용)
4. "Save" 클릭

* 이미 check.yml 안에 permissions: contents: write 적어
  뒀지만, 일부 계정 기본 설정이 read-only라 위 단계로
  명시 허용해야 안전합니다.
